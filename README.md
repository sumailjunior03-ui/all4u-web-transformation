# All4u Software Solutions LLC — Website

Official website for All4u Software Solutions LLC, a premier IT staffing and software services company operating across North America, Middle East, and Asia Pacific.

## Tech Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** for styling
- **shadcn/ui** for UI components
- **Framer Motion** for animations

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
  components/    # All page sections (Hero, Services, Industries, etc.)
  pages/         # Route pages (Index, NotFound)
  assets/        # Images and videos
  lib/           # Utilities
```
